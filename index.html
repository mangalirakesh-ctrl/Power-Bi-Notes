📈 Business Intelligence (BI) Concepts

What is Business Intelligence?

Business Intelligence (BI) is a technology-driven process that analyzes data and presents actionable information to help executives, managers, and workers make informed business decisions. BI encompasses a wide variety of tools, applications, and methodologies that enable organizations to collect data from internal systems and external sources, prepare it for analysis, develop and run queries against that data, and create reports, dashboards, and data visualizations.

Key Definition:

Business Intelligence is the process of transforming raw data into meaningful insights that drive strategic business actions.

Evolution of Business Intelligence

📊

1960s-1980s

Manual Reporting: Basic spreadsheets and manual data compilation. Limited analysis capabilities.

💾

1990s

Data Warehousing: Introduction of centralized data repositories and OLAP systems.

🌐

2000s

Web-Based BI: Online analytics, dashboards, and real-time reporting emerged.

🤖

2010s-Present

Modern BI: Self-service analytics, AI/ML integration, cloud-based solutions like Power BI.

Core Components of Business Intelligence

  1. Data Collection: Gathering data from various sources including databases, spreadsheets, cloud applications, and APIs
  2. Data Integration: Combining data from different sources into a unified view
  3. Data Storage: Storing data in data warehouses or data lakes for analysis
  4. Data Analysis: Processing and analyzing data to identify patterns and trends
  5. Data Visualization: Creating visual representations of data through charts, graphs, and dashboards
  6. Reporting: Generating and distributing reports to stakeholders

Types of Business Intelligence

📋

Descriptive Analytics

What happened? Analyzes historical data to understand past performance using reports and dashboards.

🔍

Diagnostic Analytics

Why did it happen? Examines data to identify causes of trends and patterns through drill-down and data mining.

🔮

Predictive Analytics

What might happen? Uses statistical models and machine learning to forecast future outcomes.

🎯

Prescriptive Analytics

What should we do? Recommends actions based on predictions using optimization and simulation.

⚡ What is Power BI?

Introduction to Power BI

Power BI is a business analytics service provided by Microsoft that delivers insights to enable fast, informed decisions. It's a collection of software services, apps, and connectors that work together to turn your unrelated sources of data into coherent, visually immersive, and interactive insights.

Simple Definition:

Power BI is Microsoft's self-service business intelligence tool that allows anyone to connect to data, visualize it, discover insights, and share findings across their organization.

🖥️ Power BI Desktop Interface & Views

Main Interface Overview

Power BI Desktop has a ribbon-based interface similar to Microsoft Office applications. The interface consists of three main views, each designed for specific tasks in the report development process.

Three Primary Views:

  1. Report View - Create visualizations and design report pages
  2. Data View - View and work with your data tables
  3. Model View - Create and manage relationships between tables

1. Report View (Canvas View)

📊

Purpose

This is where you spend most of your time creating visualizations, charts, and designing the layout of your reports. It's the main workspace for building interactive reports.

Key Components:

A. Ribbon Tabs

  • Home: Common actions (Get Data, Recent Sources, Transform Data, Publish)
  • Insert: Add visuals, text boxes, buttons, images, shapes
  • Modeling: Create measures, calculated columns, manage relationships
  • View: Toggle panes, gridlines, rulers, themes
  • Optimize: Performance analyzer, reduce data size
  • Help: Documentation, tutorials, support

B. Pages Pane (Bottom)

  • Add multiple report pages (tabs)
  • Rename, duplicate, delete pages
  • Reorder pages by dragging
  • Right-click for page-specific options

C. Filters Pane (Right Side)

  • Visual Level Filters: Apply to single visual only
  • Page Level Filters: Apply to all visuals on current page
  • Report Level Filters: Apply to all pages in report
  • Drillthrough Filters: Create drill-through navigation
  • Basic filtering, advanced filtering, Top N, relative date filtering

D. Visualizations Pane (Right Side)

  • 50+ built-in visuals: bar charts, line charts, maps, tables, matrices, cards, gauges
  • Custom visuals from AppSource marketplace
  • Format visual properties: colors, labels, titles, legends, data labels
  • Add analytics: trend lines, constant lines, min/max, average line
  • Conditional formatting options

E. Fields Pane (Right Side)

  • Lists all tables and columns from your data model
  • Drag fields to canvas to create visuals
  • Drag fields to visual wells (Values, Axis, Legend, etc.)
  • Search box to find fields quickly
  • Icons indicate field types: number (Σ), text (ABC), date (calendar)
  • Create measures and calculated columns from context menu

F. Report Canvas (Center)

  • Main workspace where you place visuals
  • Drag, resize, and arrange visualizations
  • Grid snapping for alignment
  • Copy, paste, duplicate visuals
  • Selection pane to manage visual layering
  • Format painter to copy visual formatting

Common Report View Tasks:

  1. Creating Visuals: Drag fields from Fields pane or click visual type first
  2. Formatting: Use Format paintbrush icon in Visualizations pane
  3. Cross-Filtering: Click on one visual to filter others automatically
  4. Drill Down: Enable drill down on hierarchies (Year > Quarter > Month)
  5. Slicers: Add interactive filters for end users
  6. Bookmarks: Capture report state for navigation
  7. Tooltips: Create custom tooltip pages

2. Data View (Table View)

📋

Purpose

View your data in table format, inspect data quality, create calculated columns, and verify transformations. This view shows the actual data loaded into your model.

Key Features:

A. Table Selection

  • Left sidebar lists all tables in your model
  • Click table name to view its data
  • Icons show table source (imported, calculated, etc.)

B. Data Grid

  • Spreadsheet-like view of data
  • Columns show field names and data types
  • Rows show actual data values
  • Scroll to view large datasets
  • Column headers for sorting (single click)

C. Ribbon Options

  • New Column: Create calculated columns using DAX
  • New Measure: Create measures for calculations
  • New Table: Create calculated tables
  • Column Tools: Change data type, format, categorization

D. Column Properties

  • Data type indicator (ABC for text, 123 for numbers)
  • Change data types (Text, Whole Number, Decimal, Date, Currency)
  • Set default summarization (Sum, Average, Count, etc.)
  • Data category (Address, City, Country, URL, Image URL)
  • Format strings (currency, percentage, custom)

E. Calculated Columns

  • Add custom columns using DAX formulas
  • Example: Full Name = [First Name] & " " & [Last Name]
  • Example: Profit = [Revenue] - [Cost]
  • Calculated columns are computed row-by-row
  • Stored in the data model (increases file size)

Common Data View Tasks:

  1. Data Inspection: Check for data quality issues, nulls, errors
  2. Column Creation: Add calculated columns for analysis
  3. Data Type Validation: Ensure correct data types
  4. Format Verification: Check number and date formats
  5. Sample Review: View sample of imported data

Note:

Data View shows only the data loaded into Power BI. You cannot edit raw data here—use Power Query Editor for data transformations.

3. Model View (Relationships View)

🔗

Purpose

Create, manage, and visualize relationships between tables. This is the data modeling workspace where you define how tables connect to each other, which is crucial for accurate analysis.

Key Components:

A. Canvas Area

  • Visual diagram showing all tables as boxes
  • Tables display table name and list of fields
  • Drag tables to arrange layout
  • Zoom in/out for better view
  • Fit to screen option

B. Relationship Lines

  • Lines connecting tables show relationships
  • Solid Line: Active relationship (used by default)
  • Dotted Line: Inactive relationship (can be activated with DAX)
  • 1 and * symbols: Indicate One-to-Many relationship
  • Arrow direction: Shows filter flow direction (cross-filter direction)

C. Creating Relationships

  • Drag field from one table to matching field in another
  • Power BI auto-detects relationships on import
  • Right-click line to edit or delete relationship
  • Double-click line to view relationship properties

D. Relationship Properties

  • Cardinality: One-to-One, One-to-Many, Many-to-One
  • Cross Filter Direction:
    • Single: Filter flows one direction (default, best performance)
    • Both: Filter flows both directions (use carefully)
  • Active: Whether relationship is used by default
  • Assume Referential Integrity: Optimization for Direct Query

E. Relationship Types

One-to-Many (1:*) - Most Common

  • One record in lookup table matches many in fact table
  • Example: One Product can have many Sales records
  • Example: One Customer can have many Orders

Many-to-One (*:1) - Reverse of Above

  • Power BI shows this as mirror of One-to-Many
  • Example: Many Sales records relate to One Product

Many-to-Many (*:*) - Advanced

  • Multiple records in both tables can match
  • Example: Students and Classes (one student takes many classes, one class has many students)
  • Requires bridge table or composite models

One-to-One (1:1) - Rare

  • One record matches one record
  • Usually indicates tables should be merged
  • Used for security or performance optimization

Best Practices for Data Modeling:

  1. Star Schema: Create one central fact table with multiple dimension tables
  2. Unique Keys: Ensure lookup (dimension) tables have unique values in relationship field
  3. Avoid Circular Relationships: Don't create loops between tables
  4. Minimize Bi-Directional Relationships: Use only when necessary
  5. Date Table: Always create a dedicated calendar table for time intelligence
  6. Hide Unnecessary Columns: Hide keys and technical columns from report view
  7. Organize Fields: Create folders for related measures

Common Model View Tasks:

  1. Create Relationships: Connect fact and dimension tables
  2. Edit Relationships: Change cardinality or filter direction
  3. Delete Relationships: Remove incorrect connections
  4. View Data Lineage: Understand data flow through tables
  5. Optimize Model: Arrange for clarity and performance

🔗 Data Modeling in Power BI

What is Data Modeling?

Data modeling is the process of creating relationships between different tables in your data, defining how they connect and interact. A good data model is the foundation of accurate and efficient Power BI reports.

Why Data Modeling Matters:

  • Accuracy: Ensures calculations and aggregations are correct
  • Performance: Well-modeled data loads faster and responds quicker
  • Flexibility: Enables complex analysis and drill-down capabilities
  • Scalability: Easy to add new data sources and fields
  • Maintainability: Clear structure makes updates simpler

Star Schema - The Ideal Structure

⭐

Concept

Star schema is the recommended data model structure in Power BI. It consists of one or more central fact tables surrounded by dimension tables, like a star shape.

Components:

  • Fact Table: Central table that stores measurable business data (transactions)
  • Dimension Tables: Descriptive tables that provide context to facts

Fact Table (Example: Sales)

  • Contains numerical, aggregatable data
  • Large number of rows
  • Connected to multiple dimension tables
FactSales - SaleID - ProductID - CustomerID - DateID - Quantity - SalesAmount - Profit

Dimension Tables

  • Smaller tables
  • Contain descriptive attributes
  • Used for slicing and filtering data
DimProduct - ProductID - ProductName - Category - SubCategory DimCustomer - CustomerID - CustomerName - Gender - City - State DimDate - Date - Year - Quarter - Month - Day

Best Practice: Fact table sits at center, dimensions around it → improves performance & simplifies DAX.

Snowflake Schema

❄️

Concept

Snowflake schema is a normalized version of Star Schema where dimension tables are split into multiple related tables.

Advantages

  • Reduces data redundancy
  • Better storage optimization

Disadvantages

  • Complex relationships
  • Slower performance in Power BI

Recommendation: Prefer Star Schema over Snowflake in Power BI.

Calendar / Date Table

📅

Why Date Table is Mandatory

  • Required for Time Intelligence functions
  • Supports Year, Quarter, Month analysis
  • Ensures correct filtering across reports

Common Date Columns

  • Date
  • Year
  • Month
  • Month Name
  • Quarter
  • Week Number

Important: Always mark Date table as “Date Table” in Power BI.

📐 DAX (Data Analysis Expressions)

What is DAX?

DAX is a formula language used in Power BI to create calculations on data models. It is used to create measures, calculated columns, and calculated tables.

👉 For **COMPLETE DAX NOTES from Basics to Advanced with examples**, visit directly: https://mangalirakesh-ctrl.github.io/DAX_Notes/

Where DAX is Used

  • Measures (Dynamic calculations)
  • Calculated Columns (Row-level calculations)
  • Calculated Tables

Measures vs Calculated Columns

Aspect Measure Calculated Column
Evaluation Calculated at query time Calculated during data refresh
Storage No storage Stored in model
Usage KPIs, totals, averages Categorization, flags

Basic DAX Example

Total Sales = SUM(FactSales[SalesAmount])
Profit = SUM(FactSales[SalesAmount]) - SUM(FactSales[Cost])

Important DAX Concepts

  • Row Context
  • Filter Context
  • Context Transition
  • Iterators (SUMX, AVERAGEX)
  • Time Intelligence

🎨 Dashboards in Power BI (Complete)

What is a Dashboard?

A dashboard is a **single-page canvas created in Power BI Service** that displays key business metrics using pinned visuals from multiple reports.

Key Point: Dashboards exist ONLY in Power BI Service, not in Desktop.

Dashboard vs Report

Feature Dashboard Report
Pages Single page Multiple pages
Source Multiple reports Single dataset
Editable Limited Fully editable

Dashboard Components

  • Pinned visuals

  • Real-time tiles

What is Power BI Service?

Power BI Service is a cloud-based platform used to publish, share, collaborate, secure, and consume Power BI reports and dashboards.

Core Components

Workspaces

Collaborative areas for teams.

Apps

Datasets
